# Docket 25-55: Attachment DOER-2-3, Coincident Peak Demands

Attachment DOER-2-3, a workbook in Eversource's 6/18/25 response to DOER's second information requests in D.P.U. 25-55, which asked how the company incurs and allocates transmission costs and which month and hour set allocated costs. Seven annual sheets (2017-2023) give system peak and rate class coincident peak demand for Eastern and Western Massachusetts. We keep it as the data behind the 12CP transmission allocation.

## Sheets

- **2017** (58 rows x 21 columns): Eastern and Western Massachusetts
- **2018** (62 rows x 21 columns): Eastern and Western Massachusetts
- **2019** (62 rows x 21 columns): Eastern and Western Massachusetts
- **2020** (60 rows x 21 columns): Eastern and Western Massachusetts
- **2021** (62 rows x 21 columns): 1
- **2022** (59 rows x 21 columns): 1
- **2023** (59 rows x 21 columns): 1
