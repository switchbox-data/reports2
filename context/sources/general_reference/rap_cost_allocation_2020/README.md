# RAP — Electric Cost Allocation for a New Era (2020)

**Full title:** _Electric Cost Allocation for a New Era: A Manual_
**Authors:** Jim Lazar, Paul Chernick, William Marcus; edited by Mark LeBel
**Publisher:** Regulatory Assistance Project (RAP)®, January 2020
**License:** CC BY-NC 4.0

This is RAP's comprehensive manual on electric utility cost allocation — the authoritative practitioner guide to embedded and marginal cost of service studies, covering functionalization, classification, and allocation of generation, transmission, distribution, and customer costs across rate classes. The manual covers both traditional methods and 21st-century reforms needed for DER, beneficial electrification, storage, and advanced metering.
