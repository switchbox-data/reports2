# Connecticut (PURA) interrogatory responses

What we learned from Docket 26-05-10 (CL&P rate case) in November 2026. Check the docket again
before relying on any of it for a new case.

## PURA does not format responses

PURA's Rules of Practice (Regs. Conn. State Agencies §§ 16-1-14 and 16-1-15) only require the front
page of a filing to show the filer's name, address, telephone, email and the docket number and title,
and require a service certification. Nothing prescribes a per-response caption, a witness line or
"Page n of N". The header on every filed response is written by the filer, and three filers in this
docket use three different layouts:

| Filer               | Header on each response                                                                                                                                                                                                           |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Eversource (CL&P)   | Company, Docket No., Set, Date Issued, response number, "Page n of N" on every page; Date Filed, Witness, Request from on the first page only; "Prior Referenced Response" reprints.                                              |
| OCC                 | "CIEC - 1", "The Office of Consumer Counsel", Witness, Docket No., "Page 1 of 1", "Date Submitted".                                                                                                                               |
| CLF and Sierra Club | Right-aligned block on every page: party, "PURA Docket No. 26-05-10", "Set CIEC-01", "Date Issued: October 21, 2026", "CIEC-001", "Page 1 of 21"; then on the first page Date Filed, Witness, Request from, Question:, Response:. |

Our Word format follows the CLF-SC one (its CIEC-1 response filed 11/04/2026, PDF made from Word),
because it is our side's own filing in the same docket. Page counts restart for every response, as in
all three.

## Filing mechanics (PURA web filing form)

- Responses are filed on the Electric docket view as "Interrogs Responses", with fields for the
  official filer, the filing firm, the date, the attached files, "Interrogatories answered: N thru M"
  and a free-text comment (CLF used "CLF and Sierra Club Response to Set CIEC-01.").
- Requests are issued on a form that takes at most 20 per filing, with integer numbers only.
- Each response is its own PDF. CLF-SC's file was named `CT 26-05-10_CEIC-1 Response.pdf` (the typo is
  CLF's); the split command names files `<file_prefix>_<label> Response.docx`.
- Attachments (Excel workpapers and the like) are separate uploads in the same filing, as in OCC's
  11/04 response (`Response to CIEC-1.pdf` plus two `.xlsx`). Confidential material goes to PURA
  separately, as OCC did.

## Open point: the set label

CIEC's first request to CLF-SC (10/21/2026, one question) was answered as "Set CIEC-01 / CIEC-001".
CIEC's 10/29/2026 request (CIEC-1 to CIEC-19, due 11/12) restarts at 1 and both PDFs on PURA's site
carry the same file name, "CIEC First Set of Requests to CLF-SC.pdf". The QMD uses "Set CIEC-02" with
labels as CIEC printed them (`CIEC-1`). Confirm both with CLF counsel before filing.

## CIEC's instructions that shape the responses

Native Excel with formulas intact where a workbook is requested; documents produced in the order
kept, with page identification; a sworn written statement for any privilege claim; and a continuing
duty to supplement or correct, with sworn responses, until a final decision.
