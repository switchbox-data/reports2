# Docket 9888: CCANDR01-11 Attachment 1, Hourly Load by Rate Class, 2024

BGE's workbook answering CCAN 1-11, which asked for test-year hourly load by rate schedule. BGE gave calendar 2024 instead, the last year of its cost-of-service load study: hourly load for every class, including heating subclasses RH and RLH, plus line losses and a reconciliation to system load. Read for the exact data BGE produced.

## Sheets

- **Sheet1** (8896 rows x 34 columns): Day, Hour, R, RH, RL, RLH, Residential
  Total, G, GS, G+GS
  Total, GL Sec, GL Sec MV90, ...
