# pa_hp_rates

Pennsylvania: Duquesne Light's Rate RA (Residential Add-On Heat Pump) and Rate RH (Residential Heating), from its 2024 rate case R-2024-3046523 and the 1997 restructuring case R-00974104 where RA first appears as its own class. RA is an equipment-based add-on rate with a thermostat lockout, closed to new customers from January 1, 2025. The record includes the nearest thing to rate design workpapers (bill frequency distributions and proof of revenue for RH/RA).

## Where the originals are

- The converted markdown and the raw workbooks are in this directory. **The original PDFs are not in the repo.** They are kept, unmodified, in a staging folder on the shared dev machine (not in git):
  `/ebs/home/jpv_switch_box/hp_rate_docket_staging/<folder>/` (path of each file is in its front matter as `original_pdf_path`). They are being uploaded to Zotero.
- Every converted markdown file has `source_url` (the URL we downloaded from, taken from our download manifest, not from the PDF) and `original_pdf_path` in its YAML front matter.
- One table with every document's URL, staged path and repo path: `/ebs/home/jpv_switch_box/hp_rate_docket_staging/PROVENANCE_FOR_ZOTERO.csv`.
- PDFs converted to markdown with the **extract-pdf-to-markdown** command (verbatim text, footnote counts checked, `<!-- PDF page N -->` markers so quotes can be cited by page). Where a file says _Partial_, only the pages relevant to the heat pump rate were extracted; the end of the file has an **Omitted pages index** saying what the other pages hold.

## Quick finder: which file answers which question

- **Final RA/RH rates (cite this):** compliance tariff `..._compliance_tariff_supp85...md`: RA winter 3.4662 c/kWh, RH winter 7.5092 c/kWh, customer charge `$13.00`; RA closes to new customers from Jan 1, 2025.
- **Rate design workpapers:** `..._exhibit1_part_iv_dfr_iv_billing_determinants_proof_of_revenue.md` (RH/RA bill frequency distributions, proof of revenue; transcribed from workbook printouts; the source has internal arithmetic inconsistencies flagged in the file). Proposed (pre-settlement) rates there differ from the final tariff.
- **Witness explanations:** Ogden direct (RA closure and customer protection, origin of RA as a legacy rate); Coleman direct (EV TOU, RS/RH/RA comparison); other parties' testimony in the omnibus file excerpts.
- **Settlement:** joint petition (11.7% distribution increase for RH and RA versus 7.5% for RS); Commission order (adopts it; contains no RA text itself).
- **Origin:** 1997 Lahtinen testimony (R-00974104) shows RA as its own class with the same add-on rules.
