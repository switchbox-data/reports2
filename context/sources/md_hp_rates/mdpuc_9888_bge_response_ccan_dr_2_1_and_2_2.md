**Case No. 9888**
**Baltimore Gas and Electric Co.**
**Response to Chesapeake Climate Action Network Data Request 2**
**Request Received: August 26, 2026**
**Response Date: October 27, 2026**
**Sponsor(s): Laura A. Wright**

**Item No.: CCANDR02-01**

For each feeder identified in response to CCAN 1-12, please provide the feeder's actual hourly metered loading or demand, in the same unit used for the feeder's rating (amps, kW, or MVA), for each of the three most recently completed calendar years (i.e., up to 8,760 hourly values per feeder per year - 8,784 in a leap year - for each of the three years). These historical values should reflect actual metered data specific to that feeder, not weather-normalized, estimated, or "representative" values (e.g., a representative load profile assigned to a class of similar feeders, rather than telemetry recorded for that specific feeder).

If the Company's systems already possess this feeder-level load data pre-aggregated to hourly resolution, please provide that data as maintained, and state whether each hourly value represents an interval average, an instantaneous/snapshot reading, an interval maximum, or some other convention used by the Company. If the Company does not already maintain this data at hourly resolution and must newly aggregate it from a finer-resolution source (e.g., SCADA data polled at a sub-hourly interval) in order to respond to this request, please use the interval average - i.e., the average metered demand over each clock-hour - as the aggregation convention.

If the Company does not possess the information necessary to produce hourly metered loading at the individual feeder level for the full three-year period (including because, for some or all feeders, the Company has only a representative or archetype load profile rather than actual metered telemetry), please provide whatever actual metered feeder-level data it does maintain and for the longest available sub-period of those three calendar years, identify the resolution and period provided, and explain in detail why the data isn't available for all feeders or for the entire requested time period.

Please provide this information in a machine-readable live Microsoft Excel or CSV format, with one row per feeder per timestamp/interval and a labeled timestamp column (not a static image, PDF, or pivoted/merged-cell table), together with the unique feeder identifier described in CCAN 1-12, item 1, so that this data can be joined to the feeder-level information provided in response to CCAN 1-12 and 1-13,. [sic] Please use the same timestamp convention - including time zone, whether intervals are labeled by interval-beginning or interval-ending, and treatment of daylight saving time transitions - as used in response to CCAN 1-8, and identify that convention.

If the Company does not possess the information necessary to produce this feeder-level hourly load data, please explain in detail why not.
