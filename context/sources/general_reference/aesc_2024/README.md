# AESC 2024 — Avoided Energy Supply Components in New England: 2024 Report

**Full title:** _Avoided Energy Supply Components (AESC) in New England: 2024 Report_\
**Authors:** Synapse Energy Economics, Sustainable Energy Advantage, North Side Energy, Resource Insight, Les Deman Consulting\
**Prepared for:** AESC 2024 Study Group\
**Date:** released February 7, 2024; amended May 24, 2024. These files extract the **amended** release.\
**Citekey:** `synapse_AvoidedEnergySupply_2024` (Zotero item `4HZWP4NM`); short link `https://pub.switch.box/synapse_AvoidedEnergySupply_2024`\
**Source:** [Synapse AESC 2024 materials page](https://www.synapse-energy.com/aesc-2024-materials) ("AESC 2024 Report - May Re-Release")

The triennial study New England's electric and gas program administrators, energy offices and regulators use to set the avoided costs that screen energy efficiency and other demand-side programs in all six states. Switchbox uses it mainly for the avoided pool transmission facility (PTF) cost, $69/kW-year in 2024 dollars (§10.2), which is the bulk transmission marginal cost in our CT (Docket 26-05-10) and RI (Docket 25-45-GE) testimony, and as a general New England reference for avoided distribution, capacity and energy costs.

The May 2024 amendment corrected only the summer on-peak energy values in Tables 8, 9, 74, 75, 156 and 160 and added the amendments page (PDF p. 18). Printed page numbers are the same in both releases; the amended PDF has one extra front-matter page, so its PDF page numbers are one higher than the original's from PDF p. 18 on.

## Page markers and citing

The PDF has 436 pages. Printed page = PDF page − 18 from PDF p. 19 (printed p. 1) to PDF p. 436 (printed p. 418); front matter is printed i–xvii (PDF pp. 2–18); the cover (PDF p. 1) prints no number.

- **Front matter.** Each file has the same flat front matter (`citekey`, `zotero_item`, `source_file`, `md5`, `pages_total: 436`, `citation_scheme: page`); `extraction_scope` says which PDF pages that file holds. The report has no line numbers, so citations are by page only.
- **Markers.** `[PDF p. N | printed p. M]` opens each page, inline where a page break falls mid-paragraph or mid-footnote. Each file marks the pages before and after its own as `[PDF pp. A-B not transcribed: …]`. Only PDF p. 122 is shared: §4.4 begins partway down it, so it is marked in both `04a` and `04b`, each holding its part.
- **Footnotes** are numbered continuously through the report (1–472); each definition sits on the page where it is printed. Tables (1–184) and figures (1–73) are also numbered continuously.
- **Finding a table or figure:** the table of tables and table of figures in `00_front_matter.md` give the printed page of every table and figure; use the page ranges below to find the file.
- **Cite** a quote with `just sources-cite <chapter file> "<quoted words>"`, which prints e.g. `p. 283 (PDF p. 301)` (cite the printed page). **Check** a file with `just sources-check-pages <chapter file>` (with the PDF from `just fetch-source synapse_AvoidedEnergySupply_2024` beside the extracts).
- **Extraction.** Transcribed from the PDF text layer, with tables read from rendered page images where the text layer scrambles them. Every figure has a `[DIAGRAM DESCRIPTION]`; values read off charts are marked approximate. Source typos and inconsistencies are kept as printed and flagged `[sic]` or `[source discrepancy: …]`; extractor notes at the top of each file list them.
